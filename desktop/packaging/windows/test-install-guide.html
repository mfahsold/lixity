Lixity for Windows

Unsigned test build for Windows x64.

Check the download

  1. Extract the archive and keep the installer and SHA256SUMS-x86_64-pc-windows-msvc.txt from the same workflow run together.
  2. Choose the _x64-setup.exe for per-user setup, or the _x64_en-US.msi or _x64_de-DE.msi for Windows Installer with the corresponding language.
  3. Open PowerShell in the extracted folder. Replace the example filename with the exact name you chose. Compare the full result with that file's entry in the checksum list.
Get-FileHash -Algorithm SHA256 -LiteralPath '.\Lixity_VERSION_x64-setup.exe'

Windows may block an unsigned installer. If the hash differs or Windows blocks the file, stop and contact the maintainer with the filename, workflow run and exact Windows message. Microsoft Defender SmartScreen

Install and open the example

  1. Close any running copy of Lixity and open the verified installer. Setup needs internet access if Windows is missing the Microsoft WebView2 Runtime.
  2. Open Lixity from the Start menu and choose Try the example offline before testing your own project.
  3. For help with startup, use Tools → Open Logs Folder once the app opens. The installation guide includes WebView2 help and the published browser and CLI setup.
