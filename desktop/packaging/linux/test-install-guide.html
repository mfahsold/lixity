Lixity Linux Test Build

This archive contains the installers for 64-bit x86 Linux. Run uname -m to check that your system reports x86_64.

Verify the download

Extract the GitHub Actions archive. Keep both installers and their checksum file together and run the following command from that folder.

sha256sum -c SHA256SUMS-x86_64-unknown-linux-gnu.txt

Proceed once the installer you intend to use reports OK.

Choose one installer

Close any running Lixity window. Use the exact downloaded filename in place of the example name containing VERSION. For a clean-install test, use a fresh Linux virtual machine.

Debian package

On a Debian-based desktop such as Ubuntu, your package manager can install the .deb and resolve its system dependencies, including WebKitGTK 4.1.

sudo apt install ./Lixity_VERSION_amd64.deb

After installation, open Lixity from your applications menu.

AppImage

Make the .AppImage executable and launch it from the folder where you want to keep it.

chmod u+x ./Lixity_VERSION_amd64.AppImage
./Lixity_VERSION_amd64.AppImage

If launch reports that FUSE is missing, check your distribution's FUSE 2 compatibility package. For Ubuntu 22.04 it is libfuse2. For Ubuntu 24.04 it is libfuse2t64. On a supported Debian-based system, the Debian package is another way to start Lixity. AppImage FUSE instructions

Start with a manuscript

Choose Try the example offline to preview the bundled manuscript. You can also open a separate project folder or import a test manuscript. Choose Tools → Open Logs Folder to inspect startup logs once the app opens.
