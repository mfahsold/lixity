Install Lixity

  1. In the disk image window, drag Lixity onto Applications and wait for the copy to finish.
  2. In Finder, open Applications and double-click Lixity. You can then eject the disk image.

Start with a manuscript

At the welcome screen, open a project folder, import a manuscript, or start writing. Choose Try the example offline to preview the bundled English manuscript before saving a local copy.

Lixity installieren

  1. Ziehe im Fenster des Disk-Images Lixity auf Programme und warte, bis der Kopiervorgang abgeschlossen ist.
  2. Öffne im Finder Programme und klicke doppelt auf Lixity. Danach kannst du das Disk-Image auswerfen.

Mit einem Manuskript beginnen

Auf der Startseite kannst du einen Projektordner öffnen, ein Manuskript importieren oder mit dem Schreiben beginnen. Mit Beispiel offline ausprobieren siehst du das englische Beispielmanuskript in der Vorschau und kannst eine lokale Kopie speichern.
