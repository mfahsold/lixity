Lixity

Check a test build

If Finder shows Lixity Test Build, confirm where the disk image came from and compare its SHA-256 with the checksum file supplied with the same build. macOS may block the first launch of a test build. For the exact alert, see Apple’s app-opening guidance.

Install Lixity

  1. In the disk image window, drag Lixity onto Applications and wait for the copy to finish.
  2. Eject the disk image. Open Applications in Finder and double-click Lixity.

Start with a manuscript

Choose Try the example offline, check the destination, and choose Import and analyze manuscript to create a local copy you can edit. You can also open a project folder or import a manuscript.

Find help

If the app opens, choose Tools → Open Logs Folder to inspect the startup log. The installation guide includes log locations and the published browser and CLI setup for cases where the app cannot open.
