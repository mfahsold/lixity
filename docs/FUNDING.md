# Project funding and use of funds

Lixity is an open-source manuscript workspace. You can use it under the
[AGPL-3.0-or-later](LICENSING.md) license without paying. We are preparing a
way for people who find Lixity useful to support its continued development.

**Payment status:** Setup is in progress. A public checkout and its payment
recipient have yet to be verified. ROST Services GmbH operates the project.
The payment provider, verified recipient and available payment options will
be listed here when the route is ready.

## What the first funds are intended to support

| Priority | Planned work | Current status |
| --- | --- | --- |
| Public desktop installers | Publish qualified installers for macOS, Windows and Linux. Cover macOS signing and notarization, Windows signing and clean-system install, upgrade and rollback checks. | The desktop app and test builds exist. Publisher qualification is underway. |
| Android and iOS / iPadOS ports | Adapt the workspace and local project storage for phones and tablets. Prototype offline analysis and verify that projects and backups can be recovered before distributing native builds. | Planned. The responsive browser interface is available today. |

The desktop targets and test-build status are in the
[installation guide](guides/installation.html#desktop). For mobile, distribution
and any payment links will be reviewed for the selected store and storefront.

## What project support covers

Project support is optional and independent of software access. The same
open-source license applies. Any commercial license, individual support or
custom development is handled separately. A provider's payment receipt is
separate from a charitable contribution receipt. Lixity does not offer
charitable contribution receipts for this support.
