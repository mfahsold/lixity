# Support Lixity

Lixity is an open-source manuscript workspace. You can use it under the AGPL-3.0-or-later license without paying. Optional project support helps fund its development.

<a id="payment-status"></a>

## Payment status

ROST Services GmbH operates Lixity and is setting up GitHub Sponsors for the project. The organization’s public checkout is pending. This page will list the payment options when the checkout and recipient are confirmed.

For funding questions, contact ROST Services GmbH.

[info@rost-services.de](mailto:info@rost-services.de)

<a id="priorities"></a>

## What the first funds are intended to support

- **Public desktop installers.** Qualify macOS, Windows and Linux installers. Cover macOS signing and notarization, Windows signing, and clean-system install, upgrade and rollback checks. The desktop app and test builds are already available. [See current downloads](installation.html#desktop).

- **Android and iOS / iPadOS ports.** Adapt the workspace, offline analysis and local project storage for phones and tablets. Verify backup and recovery before distributing native builds. This work is planned.

Mobile distribution and any payment links will be reviewed for the selected store and storefront.

<a id="license-and-support"></a>

## Software access and project support

Project support is optional and independent of software access. The same open-source license applies. Commercial licensing, individual support and custom development are handled separately. Lixity does not issue charitable contribution receipts for project support. [Licensing guide](https://github.com/mfahsold/lixity/blob/main/docs/LICENSING.md).
