Support Lixity

Lixity is an open-source manuscript workspace. You can use it under the AGPL-3.0-or-later license without paying. Optional project support helps fund its development.

Payment status

ROST Services GmbH operates Lixity and is setting up GitHub Sponsors for the project. The organization’s public checkout is pending. This page will list the payment options when the checkout and recipient are confirmed.

For funding questions, contact ROST Services GmbH.

info@rost-services.de

What the first funds are intended to support

  • Public desktop installers. Qualify macOS, Windows and Linux installers. Cover macOS signing and notarization, Windows signing, and clean-system install, upgrade and rollback checks. The desktop app and test builds are already available. See current downloads.
  • Android and iOS / iPadOS ports. Adapt the workspace, offline analysis and local project storage for phones and tablets. Verify backup and recovery before distributing native builds. This work is planned.

Mobile distribution and any payment links will be reviewed for the selected store and storefront.

Allocation log

November 2026. The first funds are intended for public desktop installers and the Android and iOS / iPadOS ports. This disclosure has no recorded figures for receipts, commitments or spending yet.

We will add dated summaries as funds are received, committed or spent. Each entry will state the period, currency and funded work.

Software access and project support

Project support is optional and independent of software access. The same open-source license applies. Commercial licensing, individual support and custom development are handled separately. Lixity does not issue charitable contribution receipts for project support. Licensing guide.
