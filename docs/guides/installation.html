Install Lixity and open a manuscript locally

Explore sentence rhythm, vocabulary and style patterns in your Markdown manuscript. Lixity runs its analysis on your computer and saves a dashboard you can open in a browser. No account or manuscript upload is required.

Maintained by the Lixity project · Updated 10 October 2026

What do I need?

Install Python, Git and uv. These examples use Python 3.12; 3.10 or newer is supported on Linux, macOS and Windows. Installation needs an internet connection. Analysis runs offline afterward. PDF import has additional requirements.

Install Lixity

uv tool install --python 3.12 "git+https://github.com/mfahsold/lixity.git@v2.3.0"
lixity --version
lixity about

This selects a fixed release from GitHub. If lixity is not found, run uv tool update-shell, reopen the terminal and try again. See the release notes for changes and compatibility.

For unreleased development work, replace the installation with:

uv tool install --force --python 3.12 "git+https://github.com/mfahsold/lixity.git@main"

main changes over time. Most users should keep the fixed release. See the update instructions when selecting a newer version, and restart any running Lixity server afterward.

Create the first dashboard

Save this synthetic text as sample.md. Two short chapters are sufficient to exercise the workflow, but not to establish a reliable stylistic baseline.

## Chapter 1

The rain stopped. Mara opened the window. The street was quiet.

## Chapter 2

At the library, Mara examined a handwritten catalogue while the keeper searched the shelves.
lixity dashboard sample.md --language en -o sample-dashboard.html

Open sample-dashboard.html in your browser. Use a longer manuscript with several chapters for more informative results, and read how to interpret them. Choose --language de for German or --language en for English. English is the default; --language auto explicitly requests detection.

Optional Zotero Desktop

For source capture, install Zotero 10 or later on the same computer and enable its local API in Settings → Advanced. Download the attachments you need. Lixity can browse collections and retain selected PDF/text attachments with your permission. No cloud account is needed. See Zotero capture and migration; images, audio and video remain in Zotero.

Open an existing project and research archive

lixity serve /absolute/path/to/project --host 127.0.0.1 --port 8765

Replace the example path with your project folder. Open http://127.0.0.1:8765/ and check the project name in the workspace bar. Open Project switches this server to an existing folder and its research. CLI analysis, research and build commands do not switch an already running server. New Project → Import Manuscript creates a separate project from uploaded text.

For a research-only workspace, an initialized archive can be opened without a manuscript. Source records remain available; comparing sources with manuscript text needs a loaded manuscript.

Switch between Research & Dossiers, Manuscript & Analysis, and Project & Settings. New Project, Open Project and optional guidance are available in every view. Selecting or dropping a manuscript opens its preview directly; confirm to create a separate project. Source and dossier filters narrow their lists; Research → Search looks through retained text.

The first-session guide explains these controls. The NDA generator downloads agreement text with name, optional address, project, date and place; it does not keep a recipient register.

Running the server day to day

The workspace uses http://127.0.0.1:8765/ by default. Built-in analysis runs on your computer; optional integrations have their own setup and data handling. Tabs connected to one server share its active project.

Stop a foreground server with Ctrl+C. After a computer restart, run the same lixity serve /path/to/project command; no reimport is needed. After updating Lixity or changing OCR settings, stop and restart the server. A browser reload alone does not update its running code.

Optional background launchers and login startup are described in the server setup reference. Lixity does not install a startup service automatically. Start Zotero for new captures; retained research stays readable when it is closed.

The project exists, but the server cannot open it

The chooser shows folders available to the computer and account running Lixity. A container or service account may have different access from your terminal. Check the project path and permissions, then restart the intended server. Use Open Project to reconnect the original folder rather than importing another copy.

If port 8765 is already occupied, identify the existing server or use --port 9000. Changing ports leaves the previous instance running. See installation troubleshooting.

Using the Python API?

Install Lixity in your Python project's own environment. The isolated command-line installation does not make import lixity available to other Python programs. See the Python setup commands.
