# Lixity 1.25.0 — Coherent measurements and clearer interpretation

This release follows the mathematical and linguistic audit with corrections to
measurement, shared text handling and the explanations shown in the application.
The scene/register and research revision workflows from 1.24 remain available.
No book-specific results, genre targets or quality scores are built in.

## Rebuild earlier comparisons

Existing JSON field names and schema versions remain. Rebuild exports and
reference comparisons with the same text and settings: these fixes can change
values, available axes and chapter/scene boundaries.

- **Style axes:** covariance, scores and explained variance now use standardized
  tied ranks on one complete chapter set. Missing measurements are not replaced
  with zero. The plot shows chapter coverage; passport metadata declares the
  space, covered chapters and minimum observation/feature counts. These minima
  allow calculation, not reliable narrator classification.
- **Structural calculations:** exact unpruned dynamic programming replaces an
  invalid pruning rule for the guarded changepoint cost. Per-endpoint centring
  avoids losing small differences after distant observations. The legacy Python
  name `pelt_changepoints` remains; runtime is quadratic, storage linear.
  Wasserstein handles unequal samples correctly; KS handles identical samples
  and small distances. Nonfinite samples fail rather than hanging.
- **Estimator conventions:** MTLD averages forward/reverse lengths. Sn uses the
  original low/high median definition; Qn uses 2.21914. Finite-sample corrections
  are not added. Kendall's unchanged normalization is labelled tau-a.
- **Text scope:** analysis and source comparisons share prose that excludes
  metadata, headings, comments, code and footnote definitions, retaining quoted
  prose. Paragraph profiles cover body/list blocks only; legacy whitespace fields
  remain distinct.
  Word-pattern flags, accented German/English words, emphasis and LF/CRLF
  boundaries agree across analytical surfaces. The short-paragraph threshold
  includes exactly eight words.

## Read signals in context

Seven-language help uses definitions and reading examples; the existing guides
and reference documentation explain conventions and limits. Nominal BH/BY
selections do not guarantee false-discovery control for a baseline fitted to the
same chapters.
Approximate trend/KS probabilities and fitted graph-tail statistics do not
confirm literary structure. Passive, modal, syllable and readability measurements
remain heuristics; a clear diagnostic is not an instruction to rewrite.

See [Methods](../METHODS.md), [Stability](../STABILITY.md) and the
[interface reference](../AGENTS.md) for units, availability and compatibility.

## Keep routine work smaller

Word frequencies reuse syllable calculations within each request. Empirical
distribution comparisons share a sorted merge; segmentation accumulates centred
moments instead of repeatedly slicing segments. Bounded independent reference
tests cover the corrections without putting large corpora or simulations in CI.

Compatibility Python versions retain all non-native tests; Linux Python 3.12 and
macOS cover native PDF extraction. Browser/platform workflows use built-in path
filters and cancellation, while core checks remain unconditional. Release checks
explicitly install Poppler. Public screenshots are regenerated from public-domain
and synthetic examples, with features embedded in their existing explanations.
