# Lixity v0.9.2

Lixity v0.9.2 updates the published Python package for the local browser
workspace, CLI and API. The desktop workflow builds version-matched test
installers for Apple Silicon, Intel Macs, Windows x64 and Linux x64.

## Highlights

- Try the desktop workspace with native project and export dialogs, an offline
  manuscript example and a shared recent-project list. Test installers bundle
  the analysis runtime and provide platform-specific setup instructions.
- Inspect counted passages, chapter-relative differences and tense cues in
  the manuscript. Use the analysis overview for chapter and book patterns.
- Compare quoted-word share and mean sentence length in manuscript order.
  Review quote-block lengths and organize your own scene intentions in the
  local rehearsal.
- Revisit a source or passage through its stored dossier citation and export
  the selected dossier version as PDF.

## Changes

- Desktop reading views load the exact evidence for a chapter on demand.
  The result count is available when the chapter opens.
- Opening the editor leaves revision measurements in **Versions** until
  requested. Reader display settings persist across changes of the desktop
  runtime address.
- Flesch Reading Ease is unavailable when the language profile cannot estimate
  any syllables. LIX remains available for supported word and sentence counts.
- Draft and saved revision comparisons preserve missing intervals and explain
  when a passage lacks a chapter comparison.
- Research gaps count active manuscript links. Retracted links remain
  available in manuscript link history.
- Scene reports and pacing summaries show unavailable sentence-length
  measurements when the required sentences are absent.
- Research comparisons use `research-comparison-local/2`. When the source and
  manuscript use different analysis languages, the report retains
  measurements for each text and marks lexical comparisons unavailable.
- Numerical routines preserve representable results across extreme scales.
  Direct structural statistics reject nonfinite inputs and unequal Spearman
  pairs. Independent reference tests cover the revised boundaries.

## Installation

Use the installation guide for the published Python package and updates. For
desktop testing, sign in to GitHub and select a successful build for the
v0.9.2 commit from the desktop workflow. macOS test images use ad-hoc
signatures. Windows test installers are unsigned. Public desktop downloads
follow publisher signing and installation checks on the target systems.
