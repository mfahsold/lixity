# Lixity v0.8.1

Released on 2026-11-14.

## Highlights

- **Manuscript Editor Formatting Bar**: Direct `H2`, `B`, `I`, and `—` buttons plus `Ctrl+B`/`Ctrl+I` shortcuts in the embedded CodeMirror editor.
- **Expanded Offline Browser Sandbox**: Interactive sentence-by-sentence rhythm sparkline, dialogue vs. narration voice contrast, clickable word echoes, highlight layer filters, local `.txt`/`.md` file drop, and Markdown report copy.
- **Analysis Legend & Scroll-Margin Fixes**: Inline-evidence layers (`sticky`, `dialogue_tag`, `indirect_speech`, `echo`) no longer display misleading comparison-unavailable banners, and `setPassageScrollMargin` only counts unstuck sticky bars by their stuck top offset.
- **Calm, Readable Product Tour**: 48-second 6-scene product tour tuned for prose readability alongside updated 16:9 and 9:16 social highlight clips.
- **Faster Verification**: Parallel `pytest-xdist` test execution (`-n auto`), longest-first Playwright scheduling, and a fast representative browser matrix (`make browser` / `make browser-changed`) with full 7-locale coverage via `make browser-full` (`LIXITY_BROWSER_FULL=1`).
- **Navigation & Scroll-Anchor Documentation**: Updated `docs/WORKSPACE.md` and `tests/browser/README.md` with the unified cross-view jump/scroll-anchor contract.
