# Lixity v0.5.0

Released 19 October 2026. Named chapter registers make intentional changes of
voice explicit, while manuscript associations retain the reviewed claim version
when an anchor and claim change together. Closed paragraph panels also create
less live document content without losing offline search.

## Intentional chapter registers

Project Settings now edits named registers, optional feature ranges and chapter
assignments in all seven interface languages. Configuration is saved only to
the selected project, with validation and stale-save protection.

Assigned chapters keep their book-relative values and baseline membership, but
are exempt from chapter deviation and FDR flags. Author ranges are separate,
descriptive comparisons, not a new statistical baseline or quality score.
Numeric selectors match exactly: selecting chapter 1 does not select 10–12.

## Research associations and CLI

- `reconcile-manuscript --accept-claim-updates` can advance reviewed claim pins
  alone or together with a moved or edited quotation. A combined update creates
  one association revision containing both changes, preserving earlier history.
- Explicit batch snapshots reject intervening archive writes. Archive read,
  write, lock and safety failures stop reconciliation with exit code 1.
- `unlink-manuscript` retracts an association without deleting its history and
  remains usable when the manuscript cannot be read.
- Manuscript commands support actual JSON, table and text output. Authored
  records accept explicit `list`, `show` and `inspect` forms, with an implicit
  inspect by ID; `--latest` is available for single-author record updates.
- Text details and diffs display stored terminal controls literally while
  preserving prose lines. Machine-readable records retain their original data.

Research remains an experimental, explicit-project API. Retaining quotations
still requires explicit consent; an association is not an accepted claim.

## Analysis and interface

The local echo detector reports repeated phrases that meet the minimum count
inside the configured word window. Independent phrases sharing vocabulary are
retained. Echoes are review hints, not instructions to rewrite prose.

Closed paragraphs create their inner layout only when opened and release it
again on close, except when preserving a marker draft. Full manuscript text
remains embedded for offline search and saved quotation links. Keyboard section
navigation, skip-to-content focus and loading-state accessibility also improve.

Invalid MATTR windows, MTLD thresholds and impossible Maas token/type counts now
raise `ValueError`; valid inputs and default arithmetic are unchanged.
The unsupported `pdf --json` combination now reports a usage error before
writing anything, rather than silently producing a PDF.

## Compatibility and validation

Style JSON retains schema version 4 with additive `register_profiles` and
`register_targets` fields. Existing book-relative measurements keep their
meaning. Existing manuscript association history is preserved.

Regression coverage includes exact chapter selection, independent echoes,
combined anchor/claim updates and stale batch snapshots. Numerical tests use
independent reference values; consolidated tests retain distinct failure cases
and remove duplicate setup and empty-result assertions. Browser checks retain
all seven locales at desktop and mobile widths.

## Documentation and discovery

Guides and blog articles expose generated Markdown alternatives. The comparison
guide's table now survives conversion. Canonical URLs, actual image dimensions,
structured metadata and meaningful modification dates have staged-site checks.
The agent index points to current commands and authoritative contracts; the
full documentation bundle remains available for offline reading.

Article wording now distinguishes paragraph observations from chapter-level
statistics, opening-chapter HTML examples from full PDF reports, and retained
source evidence from authored manuscript associations.
