# Lixity v0.4.7

Released 16 October 2026. A correctness-and-polish release: sentence metrics
agree across every panel, statistically fragile comparison values are withheld
behind documented floors, manuscript review tolerates edits outside the quoted
text, and the local dashboard server gains a documented security baseline.

## Correctness

- **Sentence metrics agree.** Sentence boundaries never cross a blank line: a
  block without terminal punctuation (stage note, salutation, sign) stays one
  unit, so chapter ASL, scene measurements, the corpus sentence histogram and
  the chapter matrix agree. Recompute older reports before comparing figures.
- **Comparability floors.** Chapters below 100 words receive no style-reference
  z-scores or FDR marks, and sentence-distribution features need five
  sentences; showing/telling and its rankings apply the same word floor. The
  dashboard marks unavailable values with a dash and explains the minimum in
  the panel; `lixity about` reports `min_comparable_words` and
  `min_comparable_sentences`.
- **Tolerant anchors.** A paragraph edit outside the retained quote now reports
  `adjusted` instead of `changed`; `lixity research reconcile-manuscript
  --accept-moved` (or the review tab's accept action) re-pins line span,
  paragraph hash and offsets as a new revision. Editing the quote itself still
  requires review, and nothing is re-pinned automatically.
- **Chronology.** A plain hyphen between four-digit years (`1929-1933`) is
  recognized as a same-precision range next to the typographic dashes.

## Dashboard and interface

- The analysis view no longer reserves blank space for closed scene details.
- Count labels use singular forms (`1 Datei`, `1 Treffer`, `1 Zuordnung`) in
  all seven languages.
- Serving the dashboard re-renders when the manuscript changed on disk, so an
  open page never shows stale numbers.

## Security

- The dashboard shell carries a per-response nonce Content Security Policy
  (default-deny, inline styles only) plus `Cross-Origin-Opener-Policy` and a
  `Permissions-Policy` denying camera, microphone, geolocation, USB and serial
  access.
- Access and debug logs keep the route without its query string, so research
  context and project tokens never reach log files. `SECURITY.md` documents the
  full local-server baseline.

## Compatibility

- Product version 0.4.7; JSON schemas and research storage are unchanged.
- Sentence statistics and withholding change numbers: recompute older reports
  and dashboards before comparing values across versions.
- Existing research archives stay readable (through `research-local/7`); the
  adjusted-anchor state is an additive review value.
- `uv tool upgrade lixity` selects this release; the pinned wheel is
  `lixity-0.4.7-py3-none-any.whl`.
