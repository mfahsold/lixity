# Lixity v0.4.5

Released 15 October 2026. A feedback release for day-to-day research work:
faster archive commands, a preview mode for record edits and clearer failure
messages.

## Improvements

- `lixity research <record> --diff` previews an update as a terminal unified
  diff (dossier bodies line by line, other fields as before/after values) and
  never writes; `--help` and error messages name the update requirements.
- Research list commands read only the record kinds they display plus
  withdrawal state: `lixity research claim list` on a 22k-record archive drops
  from about 3.4 s to 0.38 s. The accepted snapshot digest and every JSON
  envelope stay unchanged; write paths and lookups keep full-archive
  validation.
- `lixity build` reports an unwritable `exports/` folder (sandbox, read-only
  mount) as one `[error]` line with a `--dry-run` hint instead of a traceback.

## Compatibility

- Product version 0.4.5; JSON schemas and research storage are unchanged.
- `uv tool upgrade lixity` selects this release; the pinned wheel is
  `lixity-0.4.5-py3-none-any.whl`. Notes with product versions such as 1.18.0
  or 3.0.1 predate the 0.3.0 renumbering.
