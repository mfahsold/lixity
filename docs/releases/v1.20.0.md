# Lixity 1.20.0 — Research workflow ergonomics, NDA capability and UI parity

Lixity 1.20.0 introduces substantial workflow ergonomics for the research engine
(Issue #11), integrates project-isolated Non-Disclosure Agreement (NDA) management
into the native server and dashboard (Issue #12), and brings the web research
interface up to parity with new decision-linking and section inspection features.

## Research workflow ergonomics

- **Automatic fresh search indexing**: The research catalogue now automatically detects
  stale FTS5 index state and rebuilds before executing searches by default. An explicit
  `--strict` flag allows automated systems or tests to fail instead of reindexing.
- **Batch ingestion**: `lixity research ingest` supports multiple file inputs,
  emitting structured `research-batch-ingest-local/1` payloads with per-file outcomes
  and optional `--progress` reporting to stderr.
- **Section-bounded dossier reads and revisions**: Read specific dossier sections
  via `--section <name>` or retrieve structured outlines via `--summary`. Revise
  individual markdown sections without rewriting entire dossier documents.
- **Decision-dossier linking and review tracking**: Author decisions can now link
  directly to dossiers or underlying claims, automatically flagging dossiers with
  `review_needed` when a linked decision is created or revised.
- **Zotero walkthrough & backup scope comparison**: Added clear 4-step acquisition
  guidance and a dedicated comparison table clarifying what is included in archive
  backups versus external stores.

## Project NDA management

- **Project capability provider**: Added `ProjectNdaProvider` for projects that opt
  into NDA record keeping. Recipient records, status tracking, and document exports
  are stored securely within `<project>/nda/`.
- **Encryption with PBKDF2/AES**: Optional passphrase locking encrypts records
  using PBKDF2-HMAC-SHA256 and authenticated AES-GCM (with standard library fallback).
- **Privacy & isolation**: Recipient names, notes, passphrases, and keys are strictly
  project-owned and never emitted to server logs.
- **Native server & dashboard integration**: `lixity serve` dynamically activates the
  NDA manager tab when opening a project with NDA capability.

## Web dashboard improvements

- **Dossier review indicators**: Visual warning badges on dossier cards and banners
  in the dossier inspector show authors when decisions necessitate review.
- **Section outline view**: Dossier inspector displays an outline of heading sections.
- **Search scope guidance**: When a scoped search returns 0 hits, a contextual hint
  offers one-click switching to search across all records.

## Installation and compatibility

```sh
uv tool install --python 3.12 "git+https://github.com/mfahsold/lixity.git@v1.20.0"
lixity --version
lixity serve ./my-novel --research-project ./my-novel --port 8765 --open
```

Stop an existing Lixity server before restarting with the new installation.
Existing research archives and manuscripts remain fully compatible.

See the [installation guide](https://github.com/mfahsold/lixity/blob/v1.20.0/docs/INSTALLATION.md),
[onboarding guide](https://github.com/mfahsold/lixity/blob/v1.20.0/docs/ONBOARDING.md),
