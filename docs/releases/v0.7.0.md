# Lixity v0.7.0

Released 19 October 2026. This release improves manuscript PDFs and brings
visual sources, places and character journeys into the existing research workflow.

## Manuscripts for editorial review

The new **A4 editorial copy** uses 12-point text, line numbers and a correction
margin of about 34 mm. It is the initial choice in the native PDF menu:

```sh
lixity pdf manuscript.md --layout editor -o editorial.pdf
```

Editorial, A5 reading and 30×60 submission layouts share manuscript composition.
Prefaces, subheadings, scene breaks, lists, quotations and section endnotes
survive export; inline emphasis uses real font styles. Reading typography no
longer shrinks with short input. The analysis report remains a separate view of
measured values, using the same PDF engine and CLI/HTTP entry point.

Embedded Markdown/LaTeX text formatting supports a bounded, documented subset.
TeX is never executed; unsupported commands or mathematical typesetting requests
fail before replacing an output file. Image references remain labelled text.
`lixity pdf --help` describes supported commands and font overrides.

Compare the same public-domain excerpt as an
[editorial copy](https://mfahsold.github.io/lixity/examples/effi-briest-editor.pdf),
[reading copy](https://mfahsold.github.io/lixity/examples/effi-briest-book.pdf) or
[submission sheet](https://mfahsold.github.io/lixity/examples/effi-briest-sheet.pdf).

## Visual and geographic research

Zotero capture now accepts PNG/JPEG through the existing retained-image pipeline,
alongside PDF/text. Preview, explicit retention, library/server guards and exact
source-version pins remain in place; the bridge never writes the Zotero library.
Image captions expose source provenance, and RIS exports use media-correct files.

Dossiers can retain bounded GeoJSON points, lines and polygons, with labels,
descriptions, periods, actors, transport and ordered waypoint names. The existing
editor, revision history, search, concurrency guards and backup retain these
fields. The offline view is a coordinate sketch, without a basemap, geocoding,
automatic routing, travel times or historical verification.

The [read-only research demo](https://mfahsold.github.io/lixity/demo/research.html) uses attributed historical
Hamburg imagery alongside explicitly fictional scene notes and journey coordinates.
It reuses the dashboard and permits local fixture reads only.

Settings now separate project details from analysis choices and explain what
is saved. The optional title/author comparison labels both project and manuscript
values; an undetected manuscript value is no longer presented as an unexplained
missing entry.

## Compatibility

Analysis/profile JSON remains schema 2 and style JSON remains schema 4. Research
supports storage versions 1–8. Ordinary dossiers retain their earlier encoding;
the first geographic save opts into record/manifest v8. Later revisions remain
v8 even after geography is cleared. Upgrade all readers before using geography:
v0.6.0 and older readers cannot open v8 archives. There is no automatic migration.

The CLI PDF default remains `report`; the native menu defaults to `editor`.
The existing embedding-adapter export contract remains available. Oversized
research records now fail before publication, preserving the prior snapshot.
