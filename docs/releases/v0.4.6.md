# Lixity v0.4.6

Released 15 October 2026. A research-workflow and dashboard-usability release:
manuscript associations reach the command line, reviews follow the paragraph
instead of the file, and the analysis view gains precise anchors and chapter
folding.

## Improvements

- **Manuscript links on the CLI.** `lixity research` gains `link-manuscript`,
  `manuscript-links`, `review-manuscript`, `find-anchor` and
  `reconcile-manuscript`. `find-anchor` and `--quote [--line]` resolve exact
  anchor fields against the displayed text, so offline scripts no longer need
  to strip inline Markdown markers themselves.
- **Paragraph-level review.** A changed source-file digest (`source_changed`)
  is informational and no longer marks associations for review while their
  paragraph hash, line span and quote still match; an edit in one chapter does
  not re-open every other link.
- **Explicit reconcile.** A uniquely moved anchor is re-pinned as a new link
  revision with the moved line span and the current file digest, from the CLI
  (`reconcile-manuscript --accept-moved`) or directly in the review tab;
  earlier anchors stay in history. Ambiguous or changed anchors are never
  re-pinned automatically.
- **Dashboard polish.** Paragraph strip chips scroll the opened passage into
  view and flash it on arrival; chapters fold from their heading (jumps and
  search steps expand them again); stale manuscript contexts offer a reload
  action; long claim lists are filterable; stable 409 codes
  (`stale-context`, `stale-archive`) map to localized, actionable messages.

## Compatibility

- Product version 0.4.6; JSON schemas and research storage are unchanged.
- `uv tool upgrade lixity` selects this release; the pinned wheel is
  `lixity-0.4.6-py3-none-any.whl`.
