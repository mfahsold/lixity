# Lixity 1.21.0 — Research engine: matrix export, Zotero batch ingest, and cross-corpus grounding

Lixity 1.21.0 extends the research engine (Issue #11) with three focused capability
additions: structured claim-evidence matrix export, robust Zotero multi-attachment
batch ingestion, and cross-corpus Markdown grounding reports. It also adds search-hit
highlighting in the Research panel and collapsible dossier section outlines in the
dashboard.

## Research workflow — claim-evidence matrix

- **Claim-evidence matrix export**: `lixity research matrix --format md|csv|json
  [--output FILE]` generates a structured overview of all claims with their linked
  evidence items, confidence levels, and source keys. The `claim_matrix()` API
  returns the same data programmatically.

## Research workflow — Zotero batch ingest

- **Multi-attachment item ingest**: `lixity research zotero-ingest --item-key <KEY>`
  resolves all eligible PDF and text attachments of a Zotero parent item and ingests
  them in a single pass. Per-attachment errors are isolated and reported without
  aborting the batch.
- **Batch attachment ingest**: Multiple `--attachment-key` values can be specified in
  a single call with safe, per-item error isolation.
- **OCR pre-flight probe**: `lixity research ocr-status --probe` tests whether the
  configured OCR backend (Baidu API or local Tesseract) can process a synthetic
  image before submitting production documents. The `ocr_status(probe=True)` API
  returns the result programmatically.
- **Explicit OCR fallback**: `--fallback` / `LIXITY_OCR_FALLBACK=1` falls back to
  Poppler `pdftotext` when OCR is unavailable or fails. Multi-page PDF detection
  uses `pdfinfo` or a binary `/Count` scan.

## Research workflow — cross-corpus Markdown export

- **Markdown grounding report**: `lixity research compare --format md [--output FILE]`
  exports a formatted Markdown document with Jaccard similarity, shared key terms
  (Dunning G² weighted), chapter density table, and top-N term breakdowns. The
  `compare_source(..., format="md")` API returns a string with overloaded return
  types for mypy strict compatibility.

## Web dashboard improvements

- **Search-hit highlighting**: Research keyword search results now wrap matched
  passages in `<mark class="search-hit">` elements, visually emphasising hits in
  the Research panel without affecting the stored text.
- **Dossier section outlines**: Dossier list cards show collapsible section outlines
  (`<details class="r-section-block">`) with section overview badges, letting users
  inspect structure without opening the full dossier.
- **Compare card — Dunning G² key terms**: The compare/grounding widget in the
  dashboard renders the top Dunning G²-weighted key terms with styled accent borders.

## Localization

- Added `research_source_key_terms` label in 7 languages (EN, DE, FR, ES, IT, PT, NL)
  for the Dunning G² key-terms display in the compare card.
