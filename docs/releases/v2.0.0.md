# Lixity 2.0.0 — Resumable imports and complete project-language NDA drafts

Large source imports can keep completed extraction for a verified retry. The
NDA exporter now produces a complete editable draft in the project's language,
with full multi-page text, instead of an English recipient receipt. The style
plot also has textual chapter scores and keyboard/touch controls.

## Resume selected imports

Use `research ingest --checkpoint library.json --allow-retention` to opt in.
Continue with the same checkpoint and `--resume`; the original files must still
exist unchanged. After another writer changes HEAD, inspect the archive and
acknowledge the current digest with `--expected-snapshot`. Completed captures
are not duplicated; ordinary ingest retains its prior output and retry behavior.

Checkpoints stay in the explicit project's `.lixity/research/imports` cache,
outside accepted evidence and research backup exports. Pending preparation
contains private source text. Use `--discard-checkpoint` to remove it without
deleting accepted records. Purge and checkpoints coordinate to prevent restoring
deleted captures. The 64 MiB checkpoint JSON limit can affect one large capture;
interrupted or unrecorded extraction can still need to run again.

## A simpler NDA generator — intentional compatibility change

Enter name, optional address, project, date and place. Preview a friendly draft
in the project's language and download PDF or editable UTF-8 text. Six short,
unnumbered sections cover confidentiality, permitted use, protected disclosure,
rights and handling the materials. Review the text and applicable circumstances
before signing; it is an editable model, not universally enforceable legal advice.

There is no recipient database, numbering, unlock flow or status administration.
`POST /api/nda-draft` and `nda.draft_document` replace the retired management
routes/provider classes and project Python export scripts. Downloads do not
write project files. Back up previous NDA data and signed documents before
regenerating them. A new software draft does not amend an agreed contract.

An explicit `nda.language` or project-owned five-placeholder UTF-8 model remains
available when needed; no law or jurisdiction is inferred from the language.

The native renderer supports the seven Latin-script locales and paginates long
documents. Unsupported characters fail visibly rather than being replaced;
download Unicode text and convert it with a suitable renderer when needed.

## Find projects, interfaces and reviewed decisions

Recently opened projects appear on the welcome screen and Open dialog, with a
clear-history action. Browse reuses the existing native chooser. Failed or
cancelled opens do not enter history; paths stay in local browser storage.

`GET /api` describes registered endpoints without requiring an open project or
reading manuscript text. CLI `--json` aliases make explicit machine output
consistent while keeping human-facing defaults. The setup guide checks local
OCR and Zotero readiness without installing tools or reading library records.

**Mark as applied** records an author's assessment for exact decision/dossier
versions. Changed versions ask for review again, and unrelated warnings remain.
This appends a `research-local/5` event and `research-manifest-local/5` snapshot;
older applications reject upgraded archives. Existing content/citation bytes
remain unchanged. Reading an old archive does not upgrade it.

Research overview requests now reuse one validated snapshot and group source
versions once per request. Existing lists and response fields stay the same;
no persistent cache is introduced.

## Use the interface with keyboard or touch

The chapter-score table uses the exact points shown in the 3D view and offers
native chapter links. Rotation and zoom have labeled buttons. Paragraph chips
and plot controls use larger targets, including when pressed. These improvements
do not constitute certification of the whole interface against WCAG.

An explicit browser debug preference now survives reload. Server request and
error-detail logs share UTC timestamps; disabling browser logs does not change
the server's debug setting. Review logs before sharing project-specific data.

Analysis estimator values and analyze/profile/passport schemas are unchanged;
the mathematical corrections and interpretation limits from 1.25 remain.
