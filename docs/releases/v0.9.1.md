# Lixity v0.9.1

This release makes manuscript analysis easier to follow from a result to the
words that produced it. It also extends manuscript-backed dossiers and keeps
multiple projects available through one local service.

## Highlights

- Read the passages behind sentence rhythm, word patterns, and repeated phrases.
  The reader shows quotation context and lets you move between the examples.
- Inspect the exact words in recognized quotations and marked speech, including
  quotations that continue across paragraphs. The analysis explains both the
  counted words and their measurement scope.
- Compare the saved manuscript and your draft using the same settings. The
  comparison pairs identifiable chapters and labels changes in share in
  percentage points.
- Navigate examples with the keyboard, read quotation context in dark mode,
  and reach word-pattern actions on narrow screens at larger font sizes.
- Use the demo's draft exercises to inspect deliberately wordy prose, a repeated
  phrase and a tense change in the same manuscript layout as the app.
- Preview what Lixity found before saving a dossier. Review chapter coverage,
  read matching passages in context, open verified manuscript locations and
  download the selected saved version as PDF. Configure place names and the
  amount of character evidence from the project workspace.

## Changes

- Analysis cards explain what is counted and suggest what to look for in the
  manuscript. Long and short sentence groups use the configured limits.
- Local phrase search highlights occurrences together and reports malformed
  search patterns in the interface language.
- The manuscript selector, analysis overview and comparison link to localized
  metric methods. The reference is also available from the demo and the public
  homepages. [Metric reference](https://lixity.de/guides/metrics/en.html)
- Version comparisons use the same analysis method for retained source texts.
  Existing stored measurements remain part of the revision history. A missing
  source leaves a gap when a compatible comparison cannot be determined.
- Retrying an interrupted save completes the version timeline from its verified
  starting revision when the retained source is still available.
- A managed local app can open additional projects in separate views at the same
  address. `lixity doctor` and `lixity service status` report the running version.
- MCP text analysis uses its explicit inputs and built-in defaults. Its style
  outlier matrix reports the measured chapter-feature cells that meet the cutoff.
- Set project-specific limits for sentence rhythm, dialogue and function-word
  cues in a disclosure with localized labels, explanations and defaults.
- Edit separate wording, chapters and notes for each term variant. Linked
  dossiers load their matches with overlap evidence from other configured terms.
- Confirm the scope of a reader export when replacing a previously selected
  dossier or section. Audio tempo help identifies where the engine applies it.
- Keep exact percentage cutoffs when saving analysis settings and counting
  function words. Recompute older comparisons from retained text when needed.
- Verify extraction provenance before generating a dossier PDF. Current and
  historical PDF exports use the selected saved version and its pinned sources.
- Reduce repeated repainting during manuscript searches and draft selection.
  The local workspace loads its diagram renderer when a diagram comes into view.
- Number the stops in dossier PDF routes so the export works with standard
  fonts on macOS and preserves the order of the saved route.
- Keep the teleprompter moving at the selected reading speed on high refresh rate
  displays, including when reading slowly.
- Reject unsupported MCP language codes and non-integer paragraph flag levels
  so invalid requests do not silently change the analysis profile.

## Try the author workflows

- Open **Analysis overview**, choose a result and follow it to the manuscript.
  Use **How it’s measured** to check the active project limits.
- In a test project, compare identical manuscript versions. Then change a
  sentence and verify the changed values and chapter match.
- Preview a dossier from the manuscript, add your own note and refresh its
  analysis. Compare the PDF for the current dossier with an older saved version.
- Repeat one journey at a narrow screen width using the keyboard.

## Verification

The v0.9.0 tag was a release candidate. The hosted macOS check stopped
its publication after finding a font compatibility issue in dossier PDFs.

The tag workflow qualifies the exact release commit with Python 3.10 and 3.12,
the Chromium matrix, native Windows and macOS tests, dependency audits, and
an isolated wheel installation. The release uses the artifacts verified by
that run. [Release procedure](https://github.com/mfahsold/lixity/blob/main/CONTRIBUTING.md#preparing-a-release)
