# Lixity v0.4.2

Released 14 October 2026. A presentation and tooling release: the analysis view
gains a section navigation, shared components replace grown one-off styles, and
the local browser checks run in an everyday fast group.

## Improvements

- **The analysis view navigates itself.** A section strip above the chapters
  links to the flagged passages, sentence lengths, scenes, motifs, style and
  chapter matrix panels, highlights the panel currently in view (scrollspy) and
  only offers panels this document actually renders. Scene details render
  off-screen content on demand, so the long scene list opens faster, and their
  tables only show project-target and register-median columns when the project
  defines them.
- **Phones reclaim the reading area.** The analysis toolbar scrolls with the
  page instead of covering almost half of the viewport while reading.
- **One control language.** A single `form-checkbox` component replaces five
  checkbox presentations in the analysis, research, project and image-dossier
  surfaces; a compact `ctl-sm` button size covers the dense research lists;
  section headings use the canonical `section-heading`; one-off classes
  (`secondary`, `ctl-primary`, `research-check`, `publication-enable`) are
  removed and guarded by tests.
- **One layout vocabulary.** A global `.row` primitive (previously only inside
  the control panels) and spacing utilities on the shared `--space` scale
  replace the decile utility names; the Pages stylesheet consumes the canonical
  design tokens without alias duplicates or a radius override.
- **Research API boundaries validate.** Claim confidence, evidence relations
  and dossier languages are normalised or rejected at the API boundary with
  clear errors; record schema versions share one declared union. The models
  carry no static-analysis suppressions.

## Fixes

- Chapters stay fully rendered while scrolling. Deferred layout had shifted
  anchor jumps and paragraph taps while the browser was still rendering
  off-screen chapters; only the heavy scene-detail tables defer now.

## Tooling

- `make browser` runs the everyday core surfaces (eight suites) on three
  parallel workers; `make browser-full` runs every suite sequentially before a
  release. `--group fast|full` and `--jobs N` select this directly. On the
  maintainer machine the everyday loop dropped from about eleven minutes to
  under one minute.

## Compatibility

- Product version 0.4.2; JSON schemas and research storage are unchanged.
- Upgrade from 0.4.1 with the release wheel
  `lixity-0.4.2-py3-none-any.whl`.
