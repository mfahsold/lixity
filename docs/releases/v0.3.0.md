# Lixity 0.3.0

Lixity's product version now reflects development maturity before 1.0. This
release retains existing features and published history, including 3.0.1.
Product versions and JSON/archive schema versions are independent. Select the
exact 0.3.0 wheel when updating across the lower product version number.

## Manuscript reading and PDF export

Open **PDF export** in the global project controls from any workspace view,
choose A5 reading copy, A4 manuscript sheets or A4 analysis report, then select
**Download PDF**. The native action uses the CLI composer and writes no server
export files. Search and manuscript chapters now precede diagnostic panels;
paragraph text appears before optional measurements.
Project switching also uses the selected book's title in the header and NDA
form, instead of carrying another workspace's startup title forward.

Corrected TrueType subsets preserve glyph metrics, composite outlines and Unicode
aliases. PDF metadata, chapter bookmarks, bounded running headers and page
numbers improve navigation. Optional publication details in **Project → Settings**
feed the A5 imprint. Empty fields infer no legal identity, rights notice or DNB
statement. See [publication guidance for Germany print and digital](../USAGE.md#publication-settings).
Exports remain fixed-layout PDFs without EPUB, PDF/UA or PDF/X certification.

## Research alongside the manuscript

Select text within one opened paragraph, choose **Link selection to claim**,
review the current claim and permit local retention before saving. A distinct
manual association stores the selected quote, exact claim version and manuscript
anchor. Changed text or claim versions request review; moved or ambiguous anchors
are not silently resolved. These checks do not prove historical truth or detect
semantic contradictions. Dossier readers show their current claims and explicit
saved manuscript-link counts, with one shared claim viewer/history action.

The first accepted manuscript association opts the archive into
`research-local/7` and `research-manifest-local/7`. Version 0.3.0 reads schemas
1–7; historical 3.0.1 cannot read schema 7. Read-only views leave older archives
unchanged. Archive exports include retained private quotes; they omit manuscript
source blobs. See [manual association contracts](../AGENTS.md#manual-manuscript-associations).

Ordinary CLI record updates can omit the global snapshot while still requiring
the reviewed record revision. Same-record changes and writer races fail without
retry or rebase. Existing association pins remain; changed associations require
explicit revisions. Supplied snapshots retain strict archive-wide checks.

## Reliability and maintenance

Title, author and publication share one prepared configuration writer. Candidate
views are built before metadata commits; failed writes preserve accepted bytes.
Text/binary output uses shared staging and atomic replacement. Changed builds
within one minute retain distinct versions. Special file nodes are rejected
without blocking the workspace.

Dashboard and Pages share canonical design tokens. Public documentation, CLI/API
references and agent guidance are aligned. Pages has a simpler introductory
hierarchy and clearer guide notices. Ignore rules cover local credential stores,
databases, backups and agent state; reviewed staging and the public Pages boundary
remain necessary.

Release preparation uses `make release-check RELEASE_TAG=v0.3.0`: existing source
and documentation checks, a fresh source-matched wheel/sdist, isolated installed
CLI smoke and checksums. The existing tag workflow publishes verified artifacts.
Restart the installed workspace explicitly after updating.
