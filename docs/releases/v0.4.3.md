# Lixity v0.4.3

Released 15 October 2026. A maintenance release: the dashboard script is split
into cohesive modules, the analysis navigation and checkbox rows are shared
components, Lixity installs from PyPI, and the JOSS software paper is prepared
in the repository.

## Improvements

- **Shared components.** The analysis section navigation renders from one
  registry (`ANALYSIS_SECTIONS`) and every checkbox row uses one component
  (`checkbox_field`), so new panels and controls reuse the same markup source.
- **Cohesive dashboard modules.** `dashboard.js` (5,524 lines in v0.4.2) now
  keeps the generic core (796 lines); tooltips, analysis interactions, research
  and project surfaces live in `tooltips.js`, `interactions.js`, `research.js`
  and `project-ui.js`. The embedded load order preserves the original
  execution sequence, verified by the browser suites.
- **PyPI first.** `uv tool install lixity` (or pipx/pip) is the documented
  primary path in README, the installation guide, the landing page and the
  machine-readable bundles; the pinned release wheel with `SHA256SUMS` stays
  available for reproducible setups.

## Tooling

- The release workflow accepts `workflow_dispatch` with a `tag` input: PyPI
  catches up without recreating an immutable GitHub release (used for the
  first PyPI upload of 0.4.2).
- `make screenshots` synchronises embedded image dimensions from the real PNG
  headers, so the documentation cannot drift from a re-render.
- Repository hygiene: `.gitignore` and the hygiene test cover local process,
  editor and tool state (`.pypirc`, `nohup.out`, logs, pid/socket/database
  leftovers, editor autosaves, further tool caches).

## Research

- The JOSS software paper draft lives under `paper/` (`paper.md`,
  `paper.bib`) with cited references; released versions are archived on Zenodo
  so a specific version can be cited.

## Compatibility

- Product version 0.4.3; JSON schemas and research storage are unchanged.
- Install or upgrade with `uv tool install lixity` / `uv tool upgrade lixity`,
  or the pinned wheel `lixity-0.4.3-py3-none-any.whl`.
