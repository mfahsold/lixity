# Lixity v0.4.8

Released 16 October 2026. A consolidation release: the interface gets one small
design system, the research lists move to a vendored component layer, the
service logs become one findable stream, and the script and stylesheet
monoliths are split along their natural seams. No API, archive or route
contract changed.

## Interface

- **One design system.** Radius, type, weight and spacing values come from one
  short ladder in `design-tokens.css`; the app and the staged documentation
  site share it. The workspace switch and the research sub-tabs use the same
  control recipe, badges and tags are one pill family, and compact controls
  keep the 44 px touch minimum on touch devices. The `visual-consistency`
  browser suite now fails when a value leaves the ladder.
- **Component layer.** The Zotero catalogue results and the four research
  record lists (sources, dossiers, claims, decisions) render through vendored
  Preact 10 + htm — pinned files, inlined into the single dashboard script, no
  build step, CSP-compatible without `unsafe-eval`. Panels mount through
  `LixityComponents.mount`, so the server-rendered loading placeholder no
  longer lingers beside the loaded list.
- **No lost state.** Source, dossier and claim cards keep an open details
  element and its loaded content across a refresh; a changed record still gets
  a fresh card. The claims evidence panel keeps loaded evidence in the list
  model instead of the DOM.

## Logging

- `src/lixity/log.py` is the one logging entry point: a `lixity.*` tree, one
  UTC line format, standard levels (`--debug`, `LIXITY_DEBUG`,
  `LIXITY_LOG_LEVEL`) and a stderr handler that follows `sys.stderr` at emit
  time. The managed service rotates an oversized `service-PORT.log` at start
  (`.1`–`.3`); `lixity service status` prints the path. Request logs keep the
  route without its query string, and log records never contain manuscript
  text.

## Structure

- `assets/components.css` holds the shared vocabulary (panels, status, focus,
  tables, badges, controls, layout primitives, utilities) with the layer order
  tokens → components → views, asserted for the standalone output.
- `assets/research.js` (3,570 lines) is split into seven topic modules; the
  concatenated bundle keeps the original statement order.
- Spinner, micro-label and table recipes are consolidated to one source each.

## Command line

- `link-manuscript`, `review-manuscript`, `find-anchor` and
  `reconcile-manuscript` accept the manuscript path positionally, like the
  analysis commands, or via `--manuscript PATH`. Exactly one of the two forms
  is required.

## Documentation

- The interpretation guide and METHODS state that `filter_density`, modal,
  passive and nominalisation densities include quoted speech, and how to read
  them together with `dialog_pct`. A narrative-only variant of these densities
  is recorded as a candidate, not part of the current contract.
- The blog article "What's new in Lixity" covers this release line in plain
  language, and the public pages ship the current screenshots.

## Upgrade

Recompute older reports once before comparing figures (sentence boundaries and
comparability floors changed in v0.4.7). Archives and research records are
readable unchanged. Machine-verified archives, examples and releases remain
available with their published hashes.
