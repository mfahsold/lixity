# Lixity 1.16.0 — native development server, local research workspace and linguistic grounding

This release introduces a standalone development server, the initial evidence-based
research workspace pilot with cryptographic source retention, and cross-corpus
linguistic comparison bridging research sources to literary manuscript chapters.
It remains source-available under LNCL-1.0 for non-commercial use.

## Highlights

- **Native development server (`lixity serve`)**:
  Built-in `ThreadingHTTPServer` with strict loopback binding (`127.0.0.1` / `localhost`),
  Host and Origin validation, 5 MB payload caps, directory traversal protection,
  live settings API (`/api/settings`), dynamic manuscript upload (`/api/load`),
  inline marker management, and `--no-project` clean empty start. Fully decouples
  development tooling from individual book project folders.
- **Evidence-based research pilot (`lixity research`)**:
  Initial local implementation of the research workspace architecture (`research-local/1`).
  Provides immutable source archiving with retention confirmation, versioned source
  criticism metadata, disposable SQLite/FTS5 lexical search, exact passage citations,
  and cryptographic audit.
- **Controlled source lifecycle (`withdraw` & `purge`)**:
  Supports non-destructive withdrawal (marking citations and tombstoning in snapshots)
  and physical purge with `--dry-run` preview, removing unshared blobs and records.
- **Cross-corpus linguistic comparison (`lixity research compare`)**:
  Connects archived research sources with literary manuscripts without mutating either
  document. Computes lexical overlap (Jaccard similarity, Szymkiewicz–Simpson coefficient),
  Dunning's $G^2$ log-likelihood keyness differential, macro-stylistic register contrast
  (sentence length ASL delta, dialogue ratio delta, Guiraud's $R$ and Yule's $K$ deltas),
  and per-chapter evidence grounding density.
- **Refreshed visual and documentation suite**:
  Updated 15 high-resolution screenshots covering desktop, tablet, and mobile layouts,
  unification of public documentation and GitHub Pages in English, and clean shell
  completion scripts for Bash and Zsh.

## Migration checklist

1. **Retire external book server scripts.**
   If you previously ran ad-hoc server scripts from within book directories, switch to
   `lixity serve --project <DIR>` or `lixity serve --no-project`.
2. **Explicit local retention for research.**
   Ingesting research sources requires the explicit `--allow-retention` flag, confirming
   local retention permission without authorizing redistribution.
3. **Preserved core analysis schemas.**
   JSON analysis schema remains `lixity-analysis/2`; the style passport remains `lixity-style/4`.
   New research operations introduce modular `research-*-local/1` envelopes.
4. **Environment and requirements.**
   Python 3.10+ remains supported; standard SQLite with FTS5 is required for research cataloguing.
   No additional runtime dependencies or ML model weights are required.

## Install or update the CLI

Requires Git and uv:

```sh
uv tool install --force --python 3.12 "git+https://github.com/mfahsold/lixity.git@v1.16.0"
lixity --version
lixity serve --no-project --port 8765
```

Wheel and source distribution downloads include `SHA256SUMS` for integrity verification.
