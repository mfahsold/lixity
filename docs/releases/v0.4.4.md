# Lixity v0.4.4

Released 15 October 2026. A maintenance release that consolidates the
installation and citation documentation and is the first version archived by
Zenodo.

## Improvements

- One installation model across README, the installation guide, the landing
  page and the `llms` bundles: install and upgrade through PyPI
  (`uv tool install lixity`, `uv tool upgrade lixity`); use GitHub Releases
  when you need a pinned, checksum-verified wheel (`SHA256SUMS`, build
  attestations); cite a released version through Zenodo.
- `CONTRIBUTING.md` documents the automated distribution chain: tagged
  releases publish to PyPI automatically (trusted publishing, on-demand
  catch-up via `workflow_dispatch`) and are archived by Zenodo.

## Compatibility

- Product version 0.4.4; JSON schemas and research storage are unchanged.
- `uv tool upgrade lixity` selects this release; the pinned wheel is
  `lixity-0.4.4-py3-none-any.whl`.
