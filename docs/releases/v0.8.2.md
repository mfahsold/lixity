# Lixity v0.8.2

Release date: 2026-11-16.

## Highlights

- Consistent single-snapshot `research_gaps()` verification (`src/lixity/research/api.py`).
- Shorter manuscript save lock & single-pass snapshot metrics (`src/lixity/manuscript_editing.py`).
- Honest `None`/unknown semantics for unsupported `indirect_speech_per_1000` and unpopulated `flags_count`, with nullable SQLite schema migration.
- Stdlib-only `O(n log n)` chapter diagnostics (`mann_kendall`, `qn_estimator`), `O(n)` constant-series fast path in `pelt_changepoints`, and a synthetic varying-chapter benchmark fixture (`scripts/benchmark_pipeline.py`).
- Author-friendly comparison table wording across all 7 homepage locales (`docs/locales/*.json`) and unified brand/social assets in `docs/assets/brand/`.
