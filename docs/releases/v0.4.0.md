# Lixity v0.4.0

Released 14 October 2026. This release turns the analysis report into a composed
document, adds the editorial review loop to the research workspace, publishes
public-domain example analyses and makes project handling recognizable.

## Highlights

- **The A4 analysis report is a document now.** It opens with a cover page and
  sets its figures as aligned tables: rows stay whole, the header row repeats
  after a page break, numeric columns right-align, and wide tables step their
  type down instead of breaking headings. The PDF carries an outline, and the
  Guiraud label prints as ``V/√N`` instead of raw LaTeX. Book covers start on
  the optical third of the page. See the complete
  [Effi Briest](https://mfahsold.github.io/lixity/examples/effi-briest-report.pdf)
  and [Pride and Prejudice](https://mfahsold.github.io/lixity/examples/pride-and-prejudice-report.pdf)
  reports.
- **Saved manuscript associations appear in the research Review tab.** Anchor
  state, review flags and the pinned quote are listed; moved, changed or
  ambiguous anchors stay unresolved and are never repinned silently.
- **Two public-domain examples** (Effi Briest in German, Pride and Prejudice in
  English) show an interactive excerpt next to the complete PDF report; the
  editorial-loop walkthrough documents the flagged-passage workflow.
- **Project handling is recognizable.** The file browser marks Lixity project
  folders and reports config, research archive, title, language and manuscript
  for the listed folder; the header shows a compact project line (chapters,
  words, file). The Project view lists the manuscript before its settings, and
  the side-by-side reader groups its controls with a close action.
- **Research record commands accept an explicit `list` verb**; read/revise
  envelopes name `kind` and `record_id` (additive); scene detection also
  recognizes spaced divider lines, em-dash rules and the asterism; the local
  server accepts IPv6 loopback hosts.

## Compatibility

- Product version 0.4.0; product, JSON and archive versions remain independent.
- Analysis/profile JSON is schema 2 and style JSON is schema 4, unchanged.
- Research archives remain readable through v7; v0.4.0 reads every archive the
  0.3.0 release wrote.
- Installation remains the signed release wheel or `git+https://…@v0.4.0`. The
  package is not yet published on PyPI; the publish job is prepared.

## Known limits

- Fixed-layout PDF only: no EPUB, PDF/UA or PDF/X preflight.
- Analysis is deterministic for fixed text and settings; heuristics are
  language-specific and documented, not quality scores. Authorship attribution
  and AI-text detection are out of scope.
- The research workspace is experimental; sources remain private evidence.
