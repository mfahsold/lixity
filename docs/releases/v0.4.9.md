# Lixity v0.4.9

Released 16 October 2026. A polish release: the local codebase browser
automation and project configuration guidance become less dependent on
manual location overrides, and the documentation site gains a proper
product presentation on top of the shared design system.

## Recent work in this line

- **CLI ergonomics.** Manuscript-link commands (`link-manuscript`,
  `review-manuscript`, `find-anchor`, `reconcile-manuscript`) accept the
  manuscript path positionally, like the analysis commands, or via
  `--manuscript PATH`; exactly one of the two forms is required. A new
  `lixity schema` command exposes the agent metadata already returned by
  `lixity about --json`.
- **PDF draft notices.** `lixity pdf` accepts `--title` (explicit document
  title override) and `--draft-notice` (a short notice appended to every
  layout's running header). `draft_notice` is also read from the project
  configuration. Neither modifies the manuscript or the archive.
- **Research anchor assistance.** Anchors that changed because the quoted text
  was edited report `changed`; `reconcile-manuscript --new-quote "…" --link-id ID`
  resolves and re-pins a uniquely resolvable replacement quote after showing a
  diff preview (`--accept-moved`, without `--new-quote`, still re-pins only
  moved or adjusted anchors). The earlier quote stays in history.
- **Interface.** The staged documentation site shares the app's component
  vocabulary, controls use the shared `.ctl` family, and the visual-consistency
  suite fails when control radii, badge shapes or sampled text sizes leave the
  design-token ladders. Compact controls keep the 44 px touch minimum on touch
  devices.
- **Documentation.** `filter_density`, modal, passive and nominalisation
  densities now state explicitly that they include quoted speech; read them
