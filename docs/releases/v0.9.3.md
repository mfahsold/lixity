# Lixity v0.9.3

Lixity v0.9.3 brings manuscript revision and spoken review closer together.
Follow a counted passage, compare it with a saved draft, or rehearse its
delivery beside the text.

## Highlights

- **Work with revisions.** Open a saved comparison from the current writing
  session. When unsaved edits exist, the editor explains your options and asks
  before replacing them with a different draft.
- **Record and review your voice.** Set a per-project limit of up to 60 seconds,
  choose an available microphone, and review the take before retaining it.
  Optional local SoundCraft trimming keeps the original take available and asks
  you to confirm the excerpt transcript.
- **Direct audio beside the text.** Edit delivery notes at the passage and
  keep voice defaults in project settings. Discard an unneeded take, remove an
  unused reference, or withdraw a reviewed dossier while preserving its history.

## Changes

- Revision comparison captures the selected inputs before remeasurement so
  ongoing reads and saves can proceed. Recovery reads preserve existing
  project journals and reject unknown schema versions.
- Research search confirms results against the archive revision used for the
  search and releases the index connection before preparing citations.
- Audio diagnostics connect requests to their worker events, with redacted
  responses in browser QA. Passage help and available keyboard shortcuts are
  explained where authors use them.
- Release candidates are qualified by exact source commit using independent
  source, browser, native and dependency checks. Release publication promotes
  the tested source archive, wheel and their attestations. Linux test DEBs
  declare their ALSA runtime dependency and check the installed app on Ubuntu.

## Installation and verification

The installation guide describes the browser workspace and CLI packages as
well as the route to version-matched desktop test installers. The desktop
workflow builds test installers for Apple Silicon, Intel Macs, Windows x64 and
Linux x64. Public desktop downloads require the publisher and platform
qualification described in the maintainer guide.
