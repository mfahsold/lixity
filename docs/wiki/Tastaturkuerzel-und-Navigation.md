# Tastaturkürzel & Navigation ⌨️

Lixity ist vollständig tastaturbedienbar und barrierefrei nach WAI-ARIA-Standards gestaltet.

---

## 1. Zentrale Tastaturkürzel

| Tastenkürzel | Kontext | Aktion |
| :--- | :--- | :--- |
| `Alt` + `1` | Global | Zur Ansicht **Manuskript** (Leseansicht) wechseln |
| `Alt` + `2` | Global | Zur Ansicht **Recherche & Dossiers** wechseln |
| `Alt` + `3` | Global | Zur Ansicht **Projekt** wechseln |
| `/` oder `Strg` + `F` | Manuskript | Manuskript-Volltextsuche öffnen |
| `Enter` | Suche | Zum nächsten Suchtreffer springen |
| `Shift` + `Enter` | Suche | Zum vorherigen Suchtreffer springen |
| `Escape` | Global | Suchleiste schließen / Modal-Dialoge & Panels schließen |
| `Alt` + `L` | Textstelle | Belegzitat für neues Dossier verknüpfen |
| `←` / `→` | Split-Pane | Dossier-Seitenpanel stufenweise verbreitern / verkleinern |
| `Home` / `End` | Split-Pane | Dossier-Seitenpanel maximieren bzw. minimieren |

---

## 2. Tabellenbedienung

* **Sortierung:** Drücken Sie auf einem Spaltenkopf `Enter` oder die `Leertaste`, um die Sortierung auf- oder absteigend umzuschalten.
* **Navigation:** Tabellenzellen mit Zahlwerten nutzen tabellarische Ziffern (`tabular-nums`) für optimale Lesbarkeit.

---

## 3. Tooltips & Shortcuts

Fast jedes interaktive Element verfügt über einen informativen Tooltip. Sofern ein Tastaturkürzel verfügbar ist, wird dieses direkt als formatierte Taste (`<kbd>`) im Tooltip angezeigt.
