# Research & Dossiers 📂

Use the [research manual](https://mfahsold.github.io/lixity/research/USAGE.md#find-a-task)
for implemented browser and CLI workflows, or follow the
[illustrated first session](https://mfahsold.github.io/lixity/guides/research-pdf.html).
This wiki page is an orientation, not a second command reference.

## 1. The Three-Tier Model: Source, Claim, Decision

A **retained source** preserves selected original bytes and, when extracted, exact
text passages. A **claim** records an author's assertion or hypothesis. An
**evidence link** connects a retained passage to an exact claim revision with an
author-assigned relation such as supports or contradicts. A **decision** records
the author's rationale and any declared departure from a claim.

A saved **manuscript association** separately connects a permitted manuscript
quotation to a claim revision. It neither imports the whole manuscript nor turns
that quotation into source evidence. Read the
[selection and review workflow](https://mfahsold.github.io/lixity/research/USAGE.md#associate-a-manuscript-quote-with-a-claim).
Hashes and saved links establish provenance, not historical truth.

## 2. Structuring Dossiers

A dossier holds authored Markdown, source citations and retained media around a
character, setting or topic. Open **Dossier alongside** to read it beside the
manuscript. Project collections organize reading order without revising the
archive. Current records and explicitly linked earlier versions remain distinct.

The manual covers [section editing](https://mfahsold.github.io/lixity/research/USAGE.md#work-on-one-dossier-section),
[Markdown round trips](https://mfahsold.github.io/lixity/research/USAGE.md#edit-an-exported-markdown-dossier),
[images and provenance](https://mfahsold.github.io/lixity/research/USAGE.md#keep-a-visual-reference-in-a-dossier),
[PDF/video attachments](https://mfahsold.github.io/lixity/research/USAGE.md#retain-a-pdf-or-video-in-a-dossier)
and [places and journeys](https://mfahsold.github.io/lixity/research/USAGE.md#keep-places-and-journeys-in-a-dossier).
See [supported Markdown and diagrams](https://mfahsold.github.io/lixity/research/USAGE.md#safe-markdown-and-offline-diagram-rendering)
for rendering limits; arbitrary HTML, CommonMark and LaTeX are not fully supported.

## 3. Grounding & Vocabulary Comparison

Grounding compares an explicitly selected source's vocabulary with the manuscript.
It reports lexical overlap, characteristic terms and chapter occurrences. These
signals do not verify facts, establish entailment or grade prose. Language and
parsing limits matter; use the
[comparison procedure](https://mfahsold.github.io/lixity/research/USAGE.md#cross-corpus-comparison-and-evidence-grounding)
for the CLI and interpretation boundary.

## 4. Zotero Integration

Zotero remains the editable source library. The local bridge previews eligible
attachments and retains only the versions you select and permit. Metadata
capture is bounded; it is not lossless bibliography import or automatic
synchronization. Follow the
[Zotero setup and capture workflow](https://mfahsold.github.io/lixity/research/USAGE.md#zotero-desktop-bridge)
and keep [tested backups of both stores](https://mfahsold.github.io/lixity/research/USAGE.md#paired-zoteroresearch-backup-and-restore).
