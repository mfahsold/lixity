Lixity

Quantitative Textlinguistik, Stilometrie und idempotente Publikationspipelines für literarische Manuskripte. Der Name verbindet TTR, Yule’s K und LIX.

ASLTTRGuiraud RYule’s K FleschLIXTempusprofile7 Sprachen

Installation

pip install git+https://github.com/mfahsold/lixity.git

Nutzung

lixity analyze manuskript.md
lixity profile manuskript.md
lixity dashboard manuskript.md -o ui.html
