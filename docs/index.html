Lixity

Quantitative text linguistics, stylometry and a self-calibrating style passport for literary manuscripts. The name combines TTR, Yule’s K and LIX.

ASLTTRGuiraud RHD-DYule’s K FleschLIXTempusprofileStilpass StildimensionenArbeitsmarker7 Sprachen

Installation

pip install git+https://github.com/mfahsold/lixity.git

Usage

lixity analyze manuscript.md
lixity profile manuscript.md
lixity style manuscript.md
lixity dashboard manuscript.md -o ui.html
lixity about
lixity completion bash

What you get

  • Sentence rhythm: staccato to hypotaxis, ASL, sentence-length architecture.
  • Lexical diversity: TTR, Guiraud R, HD-D, Yule’s K.
  • Readability: Flesch Reading Ease (Amstad), LIX.
  • Tense profiles per paragraph with line anchors and severity flags.
  • Style passport: the manuscript’s own house style, self-calibrated (robust median/MAD), significance-adjusted deviations with FDR control, and self-calibrated style dimensions – no pre-defined registers.
  • Work markers for the text editor, set from the dashboard, never rendered.

Python API for AI agents

from lixity import api
passport = api.fingerprint(text, language="de")
metrics = api.analyze(text, language="auto")

Self-describing JSON, deterministic output, full contracts in docs/AGENTS.md.
