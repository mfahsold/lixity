Install the current release

These terminal commands use uv and Git. The installation guide explains how to get them on Windows, macOS and Linux.

uv tool install --python 3.12 "git+https://github.com/mfahsold/lixity.git@v1.24.1"
lixity --version
lixity build manuscript.md --language de

Open exports/manuscript_dashboard.html in your browser. Use --language en for English. English is the default when no language is selected; detection requires --language auto.

For the live workspace, run lixity serve --no-project --port 8765 and open http://127.0.0.1:8765/.

A scientific foundation, with stated limits

Lixity measures language patterns; it does not grade literary quality or prescribe a style. A deliberate change in voice, register or subject can explain a signal.

Chapter comparisons use the manuscript's median and median absolute deviation (MAD). Adjusted deviation scores account for estimated sampling noise; optional multiple-testing procedures and effect sizes add context under their stated assumptions.

German and English have the most extensive linguistic resources and language-specific fixtures. French, Spanish, Italian, Portuguese and Dutch also have localized interfaces and analysis resources, with narrower heuristic coverage and validation. Mathematical identifiers stay language-neutral.

Common questions

Does my manuscript leave my computer?

Built-in analysis and dashboard generation run on your computer without cloud calls. Optional integrations and separately configured workers have their own setup and data handling.

Will Lixity change my prose?

Analysis describes patterns and links to passages. It does not rewrite prose. Review notes and research decisions are actions you choose yourself.

Can a high score prove that a book is good?

No. A number describes one measured aspect of this text under particular assumptions. Read the affected passages and consider their purpose. Short texts, dialect, historical spelling and mixed languages need particular care.
